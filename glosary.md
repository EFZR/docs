# Glossary

## A

- **ACID**: An acronym standing for Atomicity, Consistency, Isolation, and Durability, a set of properties that guarantee database transactions are processed reliably.
- **API (Application Programming Interface)**: A set of rules, functions, and protocols for building and interacting with software applications. It offers a library to be used by other software as an abstraction layer. An API defines the way a client application should request services from a server application.
- **Architecture (Software Architecture)**: The high level structures of a software system, the discipline of creating such structures, and the documentation of these structures. It involves the description of elements from which systems are built, interactions among those elements, patterns that guide their composition, and constraints on these patterns.
- **Array**: A data structure that can store a fixed-size sequence of elements of the same type.
- **Algorithm (Programming Algorithm)**: A set of instructions to solve a problem.
- **Authentication**: The process of verifying the identity of a user or system. This typically involves checking credentials like usernames, passwords, or biometric data to ensure that the entity is who it claims to be.
- **Authorization**: The process of determining what an authenticated user or system is allowed to do. This involves setting permissions and access levels, ensuring that the entity can only access resources and perform actions that they are permitted to.

## B

- **Boolean**: A data type that has two possible values, true or false.

## C

- **CI/CD (Continuous Integration and Continuous Delivery)**: A method to frequently deliver apps to customers by introducing automation into the stages of app development. The main concepts attributed to CI/CD are continuous integration, continuous delivery, and continuous deployment.
- **Class**: A blueprint for creating objects (a particular data structure).
- **Compiled Programming Language**: A type of programming language whose implementations are typically compilers (translators that generate machine code from source code), and not interpreters (step-by-step executors of source code, where no pre-runtime translation takes place).
- **Compiler**: A program that translates code from high-level programming language to low-level programming language.
- **Conditional Statement**: A statement that performs different actions based on different conditions.

## D

- **Data Structures**: A data organization, management, and storage format that enables efficient access and modification. More precisely, a data structure is a collection of data values, the relationships among them, and the functions or operations that can be applied to the data.
- **Database Engine**: The underlying software component that a database management system (DBMS) uses to create, read, update and delete (CRUD) data from a database. Most database management systems include their own application programming interface (API) that allows the user to interact with their underlying engine without going through the user interface of the DBMS.
- **Debugging**: The process of finding and resolving defects or problems within a computer program that prevent correct operation of computer software or a system.
- **Decorator Pattern (Programming Pattern)**: A structural design pattern that lets you attach new behaviors to objects by placing these objects inside special wrapper objects that contain the behaviors.
- **Denial of Service (DoS)**: A cyber-attack in which the perpetrator seeks to make a machine or network resource unavailable to its intended users by temporarily or indefinitely disrupting services of a host connected to the Internet.

## E

- **E2E (End-to-End Encryption)**: A method of secure communication that prevents third-parties from accessing data while it's transferred from one end system or device to another. In E2E encryption, the data is encrypted on the sender's system or device and only the recipient is able to decrypt it. Nobody in between, be they an Internet service provider, application service provider or hacker, can read it or tamper with it.
- **Expression (Programming Expression)**: In programming, an expression is a piece of code that produces a value when evaluated. Expressions can include variables, operators, literals, and function calls. The evaluation of an expression typically involves computation of its value, which may be a number, a string, or a logical value.

## F

- **Facade Pattern (Programming Pattern)**: A structural design pattern that provides a simplified interface to a library, a framework, or any other complex set of classes.
- **Float**: A number that has a decimal point.
- **Function**: A block of code designed to perform a particular task.
- **Functional Programming**: A programming paradigm where programs are constructed by applying and composing functions. It emphasizes a declarative programming style that avoids changes in state and mutable data.

## H

- **Heap (Memory)**: A region of computer's memory space that is used for dynamic memory allocation. Unlike the stack, variables created on the heap are stored until they are explicitly released or the program ends. The size of variables and data structures in the heap can be changed during runtime.

## I

- **IAAS (Infrastructure as a Service)**: A cloud computing model that provides virtualized computing resources over the internet. IAAS offers essential compute, storage, and networking resources on demand, on a pay-as-you-go basis. It allows users to scale and shrink resources as needed, eliminating the need to invest in and manage physical hardware.
- **IDE (Integrated Development Environment)**: A software application that provides comprehensive facilities to computer programmers for software development.
- **Interpreter**: A program that directly executes instructions written in a programming or scripting language without requiring them previously to be compiled into a machine language program.
- **Interpreted Programming Language**: A type of programming language for which most of its implementations execute instructions directly and freely, without previously compiling a program into machine-language instructions. The interpreter executes the program directly, translating each statement into a sequence of one or more subroutines, and then into another language (often machine code).
- **Integer**: A whole number (without a fractional component).

## L

- **Loop**: A programming construct that repeats a block of code.

## M

- **Memory Space**: In computing, memory space refers to the specific area in the memory where data is stored. It can be allocated to hold a value and can be referenced by a variable.
- **Metaprogramming**: A programming technique in which computer programs have the ability to treat other programs as their data. It means that a program can be designed to read, generate, analyze or transform other programs, and even modify itself while running.
- **Monomorphization**: A compiler optimization technique used in languages that support parametric polymorphism (also known as generics), such as Rust. It involves generating a unique copy of the function or type for each unique set of types used as parameters. This can lead to faster runtime performance but can increase the size of the compiled binary.

## N

- **NoSQL Database (Non-Relational Database)**: A type of database that provides a mechanism for storage and retrieval of data that is modeled in means other than the tabular relations used in relational databases. NoSQL databases are increasingly used in big data and real-time web applications. NoSQL systems are also sometimes called "Not only SQL" to emphasize that they may support SQL-like query languages.

## O

- **Observer Pattern (Programming Pattern)**: A behavioral design pattern that lets you define a subscription mechanism to notify multiple objects about any events that happen to the object they're observing.
- **Object**: An instance of a class.
- **OOP (Object-Oriented Programming)**: A programming paradigm based on the concept of "objects", which can contain data and code: data in the form of fields (often known as attributes), and code, in the form of procedures (often known as methods).

## P

- **PAAS (Platform as a Service)**: A cloud computing model that provides customers with a platform allowing them to develop, run, and manage applications without dealing with the infrastructure typically associated with the process. PAAS delivers a framework for developers to build upon and includes services like databases, middleware, development tools, and operating systems.
- **Pattern (Programming Pattern)**: Reusable solution to a common problem.

## R

- **Refactoring**: The process of restructuring existing computer code without changing its external behavior.
- **Relational Database**: A type of database that stores and provides access to data points that are related to one another. Relational databases are based on the relational model, an intuitive, straightforward way of representing data in tables. In a relational database, each row in the table is a record with a unique ID called the key. The columns of the table hold attributes of the data, and each record usually has a value for each attribute, making it easy to establish the relationships among data points.
- **Runtime**: The period when a program is running. It begins when a program is opened (or executed) and ends with the program is quit or closed. Runtime software is software that is running on a computer.

## S

- **SAAS (Software as a Service)**: A software distribution model in which applications are hosted by a service provider and made available to customers over the internet. This model eliminates the need for users to install and maintain software, and it can be accessed via a web browser. SAAS typically operates on a subscription basis.
- **Singleton Pattern (Programming Pattern)**: A creational design pattern that lets you ensure that a class has only one instance, while providing a global access point to this instance.
- **Stack (Memory Space)**: A region of computer memory where data is added or removed in a last-in-first-out (LIFO) manner. In a stack, the most recently added item is the first one to be removed. All data in the stack has a static size, which must be specified at compile time. The stack is used for static memory allocation, including function call parameters, return addresses, and local variables.
- **State Pattern (Programming Pattern)**: A behavioral design pattern that lets an object alter its behavior when its internal state changes. It appears as if the object changed its class.
- **Statement (Programming Statement)**: In programming, a statement is a standalone unit of code that performs a specific action. Statements control the flow of execution and initiate actions. They can include control flow statements (like if, for, while), assignment statements, function calls, or declarations. Unlike expressions, statements do not return a value.
- **Strategy Pattern (Programming Pattern)**: A behavioral design pattern that turns a set of behaviors into objects and makes them interchangeable inside original context object.
- **String**: A sequence of characters.

## U

- **UI (User Interface)**: The graphical layout of an application. It consists of the buttons users click on, the text they read, the images, sliders, text entry fields, and all the rest of the items the user interacts with.
- **UX (User Experience)**: The internal experience that a user has as they interact with every aspect of a company’s products and services. The term also refers to the study and implementation of quality interaction between users and a company.

## V

- **Variable**: A named space in the memory that stores values.
