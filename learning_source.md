# 📚 Learning Sources

## 🦀 Rust

- [Rust Documentation](https://doc.rust-lang.org/book/): The official Rust documentation provides comprehensive information about the language, its syntax, and its features.

## 🛠️ Writing an OS in Rust

- [Philipp Oppermann's Blog](https://os.phil-opp.com/): A detailed series of blog posts about creating an operating system in Rust from scratch.

## 🎮 Game Development

- [Amethyst](https://amethyst.rs/): A data-driven and open-source game engine written in Rust.

## 🌐 WebAssembly

- [WebAssembly Documentation](https://rustwasm.github.io/docs/book/): The official Rust and WebAssembly documentation provides a guide to using Rust to create WebAssembly applications.

## 🖥️ Embedded Software

- [Embedded Rust Book](https://doc.rust-lang.org/stable/embedded-book/intro/index.html): A guide to developing reliable, high-performance embedded systems with Rust.

## 🌐 Server Programming

- [Youtube Jeremy Chone](https://www.youtube.com/@JeremyChone): A YouTube channel with tutorials and guides on server programming in Rust.
