# 📚 SQL (Structured Query Language)

SQL is a standard language 🗣️ designed for managing data 📊 held in a relational database management system (RDBMS). It is used for creating, manipulating, and querying databases.

## 🧩 Components of SQL

- **DDL (Data Definition Language)**: 🏗️ This component of SQL is used for defining and managing all the objects in a database. It includes commands like CREATE, ALTER, and DROP which are used to create, modify, and delete database objects such as tables, indexes, and views.

- **DML (Data Manipulation Language)**: 🔄 This component of SQL is used for managing data within database objects. It includes commands like INSERT, UPDATE, and DELETE which are used to insert new data, modify existing data, and delete data from the database tables.

- **DQL (Data Query Language)**: 🔍 This component of SQL is used for querying the database for specific information. It includes the SELECT command which is used to retrieve data from the database.

- **DCL (Data Control Language)**: 🔐 This component of SQL is used for controlling access to data within the database. It includes commands like GRANT and REVOKE which are used to manage database access permissions.

- **TCL (Transaction Control Language)**: 💼 This component of SQL is used for managing transactions in the database. It includes commands like COMMIT, ROLLBACK, and SAVEPOINT which are used to manage changes made by DML statements.
