# C# Commands

## 🚀 Project Operations

- `dotnet new console -n <name>`: 🖥️ Create a new console application with the specified name.
- `dotnet new classlib -n <name>`: 📚 Create a new class library with the specified name.
- `dotnet new mvc -n <name>`: 🌐 Create a new ASP.NET Core MVC web application with the specified name.
- `dotnet new webapp -n <name>`: 🌐 Create a new ASP.NET Core Razor Pages web application with the specified name.
- `dotnet new webapi -n <name>`: 🌐 Create a new ASP.NET Core Web API with the specified name.
- `dotnet new sln -n <name>`: 📁 Create a new Solution file with the specified name.
- `dotnet new xunit -n <name>`: ✅ Create a new xUnit test project with the specified name.
- `dotnet new nunit -n <name>`: ✅ Create a new NUnit test project with the specified name.
- `dotnet new worker -n <name>`: 🛠️ Create a new Worker Service with the specified name.
- `dotnet new grpc -n <name>`: 📞 Create a new gRPC service with the specified name.

## 🏗️ Build and Run

- `dotnet build`: 🏗️ Build a project.
- `dotnet run`: 🚀 Run a project.
- `dotnet publish`: 📦 Publish a project for deployment.
- `dotner watch`: 👀 Watches for any change to hot reload the app.

## 📦 Package Management

- `dotnet add package <PackageName>`: ➕ Add a package reference to a project.
- `dotnet remove package <PackageName>`: ➖ Remove a package reference from a project.
- `dotnet list package`: 📝 List package references for a project.

## 🔗 Project References

- `dotnet add reference <../PathToOtherProject/OtherProject.csproj>`: ➕ Add a project reference to another project.
- `dotnet remove reference <../PathToOtherProject/OtherProject.csproj>`: ➖ Remove a project reference from a project.

## 📁 Solution Management

- `dotnet sln add <library>`: ➕ Add a project or library to a solution.

## ✅ Testing

- `dotnet test`: ✅ Run tests in a project.
