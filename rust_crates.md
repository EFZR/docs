# 🦀 Rust Crates

Rust's ecosystem is rapidly expanding with a wide array of libraries and crates that simplify the development process for various application types. This document highlights some of the most popular and widely-used crates.

## 🌐 Web Development

- [actix-web](https://crates.io/crates/actix-web): 🚀 This robust, pragmatic, and high-speed web framework is a favorite among Rust developers.
- [axum](https://crates.io/crates/axum): 🛠️ Axum is an ergonomic and modular web framework built with Tokio, Tower, and Hyper.
- [rocket](https://crates.io/crates/rocket): 🚀 Rocket is a Rust web framework that prioritizes speed, security, and flexibility without compromising on usability or type safety.
- [warp](https://crates.io/crates/warp): 🌐 Warp is a user-friendly, composable web server framework designed for high performance.
- [hyper](https://crates.io/crates/hyper): ⚡ Hyper offers a fast and accurate HTTP implementation for Rust.
- [tower-http](https://crates.io/crates/tower-http): 🗼 Tower-http is a collection of middleware, services and utilities for building web services with Tower and Tokio.
- [tower-cookies](https://crates.io/crates/tower-cookies): 🍪 Tower-cookies is a middleware for managing cookies in Tower services.

## 🗄️ Database Interaction

- [sqlx](https://crates.io/crates/sqlx): 📊 SQLx is an async, pure Rust SQL crate that supports compile-time checked queries without a DSL.
- [diesel](https://crates.io/crates/diesel): 🗄️ Diesel is a safe, extensible ORM and Query Builder for Rust.
- [sea-orm](https://crates.io/crates/sea-orm): 🌊 Sea-orm is an async & dynamic ORM for Rust.
- [sqlb](https://crates.io/crates/sqlb): 📊 SQLb is a SQL query builder and executor for Rust.
- [modql](https://crates.io/crates/modql): 📊 Modql is a modern, easy-to-use SQL query builder for Rust.
- [sea-query](https://crates.io/crates/sea-query): 🌊 Sea-query is a SQL query builder with a focus on simplicity and type safety.

## 📡 HTTP Clients

- [reqwest](https://crates.io/crates/reqwest): 📡 Reqwest is a powerful yet easy-to-use Rust HTTP Client.
- [surf](https://crates.io/crates/surf): 🏄‍♂️ Surf is a user-friendly HTTP client designed for both new and experienced Rustaceans.
- [httpc-test](https://crates.io/crates/httpc-test): 📡 Httpc-test is a library for testing HTTP clients.

## 🎮 Game Development

- [amethyst](https://crates.io/crates/amethyst): 🎮 Amethyst is a data-driven game engine written in Rust.
- [ggez](https://crates.io/crates/ggez): 🕹️ Ggez is a lightweight game framework for creating 2D games with minimal friction.

## ⏱️ Asynchronous Programming

- [tokio](https://crates.io/crates/tokio): ⏱️ Tokio is a runtime for building reliable, asynchronous, and lightweight applications with Rust.
- [async-std](https://crates.io/crates/async-std): 🚀 Async-std provides a modern, fast, and concise async API for Rust and beyond.

## 🧪 Testing

- [mockito](https://crates.io/crates/mockito): 🧪 Mockito is a server library for mocking HTTP requests in Rust.
- [proptest](https://crates.io/crates/proptest): 🧪 Proptest is a property testing framework inspired by the QuickCheck tool for Haskell.

## 📦 Additional Crates

- [tracing](https://crates.io/crates/tracing): 🔍 Tracing is a framework for instrumenting Rust programs to collect structured, event-based diagnostic information. Unlike traditional logging, it is designed to handle structured diagnostic events as well as textual log messages.
- [tracing_subscriber](https://crates.io/crates/tracing_subscriber): 🔍 Tracing subscriber provides utilities for implementing and composing `tracing` subscribers. It is often used in conjunction with the `tracing` crate.
- [uuid](https://crates.io/crates/uuid): 🆔 UUID is a library that provides support for Universally Unique Identifiers (UUIDs) in Rust.
- [serde](https://crates.io/crates/serde): 🔄 Serde is a framework for serializing and deserializing Rust data structures efficiently and generically.
- [rayon](https://crates.io/crates/rayon): ⏱️ Rayon is a data-parallelism library for Rust. It is extremely useful for tasks which can be performed in parallel.
- [clap](https://crates.io/crates/clap): 👏 Clap is a simple-to-use, efficient, and full-featured library for parsing command line arguments and subcommands.
- [log](https://crates.io/crates/log): 📝 Log provides a logging facade for Rust that abstracts over the actual logging implementation.
- [rand](https://crates.io/crates/rand): 🎲 Rand provides utilities to generate random numbers in Rust.
- [regex](https://crates.io/crates/regex): 🔍 Regex allows you to use regular expressions in Rust.
- [chrono](https://crates.io/crates/chrono): 🕰️ Chrono is a date and time library for Rust.
- [anyhow](https://crates.io/crates/anyhow): 🚀 Anyhow is a library for flexible error handling in Rust.
- [rand](https://crates.io/crates/rand): 🎲 Rand is a library for generating random numbers in Rust.
- [hmac](https://crates.io/crates/hmac): 🔐 HMAC is a "hash-based message authentication code" that provides a way to check the integrity of information transmitted over or stored in an unreliable medium, based on a secret key.
- [sha2](https://crates.io/crates/sha2): 🔐 SHA-2 (Secure Hash Algorithm 2) is a set of cryptographic hash functions designed by the National Security Agency (NSA). It is commonly used in various security applications and protocols.
- [base64-url](https://crates.io/crates/base64-url): 🔐 Base64-url is a library for encoding and decoding Base64 strings with URL and filename safe alphabet in Rust.
